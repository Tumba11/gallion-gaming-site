# Gallion Gaming

Studio site for [Gallion Gaming](https://galliongaming.com), featuring **Chopsticks**.

Chopsticks is an unofficial, free, non-commercial fan game. It is not affiliated with or endorsed by SpaceX. Play it at [catch-the-booster-390255.onrender.com](https://catch-the-booster-390255.onrender.com/).

This repository is a static HTML, CSS, and JavaScript site. There is no build step.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

## Deploy

Hosted as a Render static site from this repository. Publish path is the repo root.
